# HERO WORLD

An original offline, portrait-first open-world ARPG built with Godot 4.7.2.

## Product direction

Classic fantasy action-RPG progression: explore connected regions, fight monsters, use skills, collect equipment, grow stronger, and challenge bosses. The game supports manual and optional auto-combat, is designed for offline single-player use, and targets portrait Android devices first.

All characters, art, maps, skills, audio, names, and writing are original.

## Current prototype

- Portrait-first isometric field.
- Keyboard and virtual joystick movement.
- Desktop mouse emulation for virtual joystick review.
- Map boundary and obstacle collisions.
- GitHub Actions Godot 4.7.2 headless import and scene smoke checks.

Open `project.godot` with Godot 4.7.2 and press F5.
