# HERO WORLD｜传奇世界

原创 2D 等距视角单机 RPG。抽象参考经典传奇的成长与装备循环，以及《百炼英雄》的小队自动战斗节奏；不复制原作代码、素材、地图、角色或可识别表达。

- 引擎：Godot 4.x / GDScript
- 平台：Android 优先，macOS 开发
- 模式：完全离线，本地存档
- 战斗：队长操作、队员自动战斗，最多 6 人
