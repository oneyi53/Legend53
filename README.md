# HERO WORLD

An original offline portrait-first isometric squad RPG built with Godot 4.7.2.

## Current prototype

- Portrait-first 720 × 1280 layout.
- Rotated isometric field sized for mobile screens.
- Keyboard movement for desktop development.
- On-screen virtual joystick with mouse emulation for desktop review.
- Map boundary and obstacle collisions.
- GitHub Actions headless import and main-scene smoke checks.

## Run locally

Open `project.godot` with Godot 4.7.2 and press F5.

## Product direction

Explore a world with a small hero squad, defeat enemies through automated combat, collect loot, improve heroes, and unlock new areas. The game is designed to work offline with local saves.

All game assets, characters, names, maps, skills, and writing are original.
