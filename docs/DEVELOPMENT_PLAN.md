# 专业游戏开发计划

## 产品定位
原创竖屏单机传奇类 ARPG。以经典《传奇》品类体验为参照：单角色成长、战法道职业、野外刷怪、主动技能、装备爆落、强化、地图推进、精英怪与世界首领。不是六人英雄小队或放置卡牌玩法。

## 核心循环
城镇整备 → 野外探索 → 手动/自动刷怪 → 技能战斗 → 怪物爆装与经验金币 → 装备穿戴/强化 → 挑战精英与 Boss → 解锁更高等级地图。

## 首个可玩垂直切片
- 1 个安全城镇、至少 3 张相连野外区域。
- 战士、法师、道士三职业；单角色操控，职业属性和技能差异明确。
- 普通怪、精英怪、区域 Boss；具备索敌、追击、攻击、受击、死亡与掉落。
- 普攻、职业主动技能、冷却、范围伤害、暴击、伤害数字和攻击预警。
- 经验等级、金币、装备随机掉落、背包、穿戴与强化。
- NPC 商人、铁匠、传送向导、任务与区域解锁。
- 本地存档、断网运行、Android 竖屏 APK。

## 系统优先级
P0：可运行工程、竖屏移动、单角色战斗、怪物 AI、职业技能、Boss、数值与存档。
P1：地图与任务内容、掉落装备、NPC经济、战斗表现、音频与性能。
P2：更多地图、怪物词缀、装备品质/套装/图鉴、技能成长、首领机制、完整 Android 发布验收。

## 研发阶段
P0 工程基线；P1 世界与移动；P2 战斗循环；P3 职业技能；P4 成长与掉落；P5 城镇/任务/区域/Boss；P6 战斗表现与数值深度；P7 存档与离线；P8 Android 真机与发布候选。

## 技术方案
Godot 4.7.2、GDScript、2D 等距渲染。玩法逻辑与表现层逐步解耦；技能、怪物、装备和区域采用可配置数据。核心流程不得依赖网络。存档需保留版本迁移、备份和异常恢复能力。

## 质量标准
每次提交执行 Godot 4.7.2 headless 导入、脚本解析和主场景启动。自动化通过不等于 Android 真机验收；触控手感、屏幕比例、性能、安装和断网行为仍需设备测试。

## 合规边界
仅借鉴经典传奇类玩法结构与节奏；游戏名称、世界观、角色、地图、美术、音频、文案和代码均独立创作。


## 区域掉落与首领专属装备（新增）
- 林间入口：林地守望基础系列。
- 幽暗密林：林地守望进阶区域变体，装备属性倍率提高，品质判定获得区域加权。
- 古代遗迹：遗迹征服者系列，稀有词条更常见。
- 遗忘祭坛：遗迹征服者高阶变体，区域属性倍率进一步提高。
- 精英怪：必定掉落装备，并获得额外品质加权。
- 腐化古树：固定掉落专属传说武器、护甲与核心坠饰；每件有独立 item_id，计入装备图鉴。
- 背包装备展示掉落区域/首领来源；图鉴按唯一 item_id 统计，兼容既有存档。


## 装备锻造与材料经济（新增）
- 精英怪随机掉落 1–2 枚符文碎片；腐化古树首领奖励 5 枚。
- 铁匠提供符文锻造：每件装备消耗 100 金币与 2 枚符文碎片，最多锻造 3 阶。
- 锻造提升装备主属性；材料数量与装备锻造等级随本地存档保存，旧存档自动补齐材料字段。
