# 游戏设计概要

原创奇幻大陆远征故事。玩家控制队长，其余队员自动跟随、索敌、攻击并在条件满足时施放技能。队伍上限 6 人，首版先用 3 名英雄验证系统。

职业定位：守护、近战输出、远程输出、法术、治疗、控制。

战斗状态：探索、接敌、战斗、胜利、脱战、失败。AI 优先级：生存与危险规避、当前目标、攻击距离与技能条件、重新索敌、脱战归队。

成长系统：等级、经验、基础属性、成长属性、技能等级。装备槽：武器、头部、胸甲、护手、鞋、饰品。品质：普通、优秀、稀有、史诗、传说。

首区域暂定遗忘森林，包含营地、普通怪区、精英区、资源点、Boss 场地和章节奖励。长期规划六个章节；英雄长期目标 42 名，按系统成熟度分批开发。

UI 包含队伍状态、目标信息、技能、区域导航、背包、英雄、任务和设置。横屏作为首版优先验证方向，最终以实机测试锁定。
