# 游戏设计概要

## 产品定位

HERO WORLD 是原创的竖屏单机大世界 ARPG。以经典传奇类游戏的探索、刷怪、技能战斗、装备掉落、角色成长、精英与 Boss 挑战为体验参照；不复制任何商业游戏的角色、美术、地图、音效、文案或可识别表达。

- 单机大世界：地图区域相互连接，城镇、野外、地下区域、NPC、任务和首领构成连续世界。
- 战斗方式：手动与自动战斗自由切换。自动模式负责基础索敌与攻击；危险区域、精英和 Boss 保留手动操作价值。
- 首发平台：Android 竖屏；桌面版仅作为开发和回归测试入口。
- 离线优先：主线探索、战斗、成长、背包和存档不依赖网络服务。

## 核心循环

探索区域 → 遭遇怪物 → 手动或自动战斗 → 经验与装备掉落 → 拾取和整理 → 强化角色 → 解锁更危险的区域 → 挑战首领。

## 职业

首发核心职业：战士、法师、道士。职业差异体现在攻击距离、技能形态、生存能力和召唤/辅助机制。技能名称、图标、动画和数值采用原创方案。

## 世界结构

世界由城镇枢纽、野外练级区、精英区域、地下遗迹和首领场地组成。区域采用可探索连接，而不是仅有单屏刷怪房间。首章暂定遗忘森林，包含营地、林地、废弃矿道和古代祭坛。

## 成长与装备

成长：等级、经验、基础属性、技能等级与职业专精。
装备槽：武器、头部、胸甲、护手、鞋、饰品。
品质：普通、优秀、稀有、史诗、传说。
掉落：怪物掉落表采用数据配置；装备以稳定 ID 存储，显示名仅用于展示。

## 竖屏 UI

顶部：角色头像、等级、生命/法力、区域和小地图入口。
中部：等距世界、NPC、怪物、掉落物与交互对象。
左下：虚拟摇杆。
右下：普攻、职业技能、药水、自动战斗开关。
底部或弹出层：角色、背包、技能、任务、地图和设置。

## 首个可玩切片

一张首章野外区域、城镇入口与区域出口；战士可操作；法师/道士先作为数据和后续扩展预留。至少三种普通怪、精英变体和一个首领；实现移动、索敌、普攻、技能、死亡、经验、掉落、背包与本地存档。
