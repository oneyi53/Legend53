# 技术架构

## 分层
表现层：竖屏 UI、场景、动画、音效、特效、镜头。
领域层：世界区域、战斗、英雄、怪物 AI、装备、任务与成长规则。
数据层：英雄、怪物、技能、装备、掉落与区域配置。
基础服务：GameManager、SceneRouter、EventBus、DataRegistry、SaveManager、CombatDirector、LootService。

## 输入与战斗
输入适配层统一处理虚拟摇杆、触屏技能按钮和桌面键鼠。玩家可切换手动/自动战斗。自动战斗仅负责可配置范围内的索敌、移动接敌和基础攻击，不替代所有交互决策。战斗计算不依赖 UI。

## 数据规范
所有实体使用稳定 ID，不以显示名称作为主键。配置导入检查 ID 重复、引用缺失、字段缺失、数值越界和掉落权重异常。

## 存档
存档包含 schema_version、时间戳、区域位置、角色成长、装备背包、货币、任务和设置。先写临时文件，校验后替换正式文件，保留备份；加载时执行版本迁移，损坏时回退并提示。

## 性能
避免每帧全世界昂贵寻敌；采用定时感知和区域激活。远处 AI 降频，控制粒子和透明叠层。性能目标以 Android 实机报告为准。
