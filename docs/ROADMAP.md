# 路线图与验收标准

## 产品方向
- 原创竖屏单机传奇类 ARPG，以经典《传奇》的职业成长、刷怪、技能、爆装、强化、地图推进和首领挑战为体验参照。
- 单角色操控；战士、法师、道士三职业，不采用六人英雄小队作为核心循环。
- Android 竖屏优先；手动与自动战斗可切换；单机离线、本地存档。
- 所有角色、美术、地图、技能、音效、名称和文案原创。

## 阶段与验收
| 阶段 | 目标 | 验收 |
|---|---|---|
| P0 | 工程基线 | Godot 可打开运行，无缺失引用 |
| P1 | 竖屏世界与移动 | 竖屏布局、等距地图、触控摇杆、碰撞 |
| P2 | 基础战斗 | 普攻、索敌追击、受伤、死亡与重生 |
| P3 | 职业体系 | 战法道属性、技能、冷却与职业差异 |
| P4 | 成长与爆装 | 经验、等级、金币、掉落、背包、装备强化 |
| P5 | 传奇世界结构 | 安全城镇、NPC、任务、区域传送、精英与 Boss |
| P6 | 战斗表现 | 命中特效、暴击、伤害数字、Boss 阶段与预警 |
| P7 | 存档离线 | 本地存档、备份恢复、断网可玩 |
| P8 | Android 验收 | APK 安装、触控适配、性能、稳定性与断网测试 |
| P9 | 内容扩展 | 更多地图、怪物、装备、技能成长、套装图鉴和首领机制 |

## 自动化质量门禁
每次推送到 main 或提交 PR 时，GitHub Actions 使用 Godot 4.7.2 执行 Headless Editor 导入、脚本解析与主场景启动回归。自动化通过不等于 Android 真机验收。

首个可玩切片：1 个安全城镇、3 张野外区域、战法道三职业、普通怪与精英、至少 1 个 Boss、经验金币和装备掉落、背包强化、NPC任务及本地存档。
