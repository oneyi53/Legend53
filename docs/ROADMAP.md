# 路线图与验收标准

| 阶段 | 目标 | 验收 |
|---|---|---|
| P0 | 工程基线 | Godot 可打开并运行，无缺失引用 |
| P1 | 地图移动 | 等距地图、碰撞、镜头和跟随稳定 |
| P2 | 战斗原型 | 自动索敌、普攻、技能和敌人 AI 可完整结算 |
| P3 | 成长闭环 | 经验、装备、背包数据可保存恢复 |
| P4 | 首章内容 | 可从入口推进至 Boss 并通关 |
| P5 | 离线 Android | 飞行模式可玩，强制关闭后可恢复，APK 可安装 |
| P6 | 内容扩展 | 配置校验与核心回归通过 |
| P7 | 发布候选 | 无 P0/P1 缺陷，兼容性报告齐全 |

首个切片：1 张地图、3 名英雄（架构支持 6 人）、3 种普通怪、2 种精英、1 个 Boss、15–20 件装备、3–5 个技能样例，体验目标 10–25 分钟。

发布前验证：核心流程、离线运行、存档恢复、30 分钟稳定性、Android 安装与前后台切换。签名密钥不得提交仓库。
