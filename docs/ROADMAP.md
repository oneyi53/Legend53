# 路线图与验收标准

## 产品方向
- 原创竖屏单机大世界 ARPG，以经典传奇类游戏的刷怪、技能、爆装、成长和首领挑战为体验参照。
- Android 竖屏优先，桌面运行仅用于开发与回归。
- 手动与自动战斗切换；单机离线，本地存档，不依赖在线服务。
- 角色、美术、地图、技能、音效和文案全部原创。

## 阶段与验收

| 阶段 | 目标 | 验收 |
|---|---|---|
| P0 | 工程基线 | Godot 可打开并运行，无缺失引用 |
| P1 | 竖屏世界与移动 | 竖屏布局、等距地图、触控摇杆、键鼠调试、边界和障碍碰撞 |
| P2 | 基础战斗 | 玩家手动/自动模式、怪物索敌追击、攻击、受伤、死亡与重生 |
| P3 | 职业技能 | 战士技能、冷却、范围判定、伤害反馈 |
| P4 | 装备掉落 | 经验、掉落、拾取、背包和穿戴 |
| P5 | 大世界结构 | 城镇、区域连接、NPC、任务、精英和 Boss |
| P6 | 存档与离线 | 版本化存档、备份回退、断网可玩 |
| P7 | Android | APK 安装、触控适配、性能与稳定性 |
| P8 | 内容扩展 | 法师、道士、更多区域和装备 |

## 自动化质量门禁
每次推送到 main 或提交 Pull Request 时，GitHub Actions 使用 Godot 4.7.2 执行 Headless Editor 导入、脚本解析与主场景启动回归。自动化通过不等于 Android 真机验收；触控手感、屏幕比例、性能和安装流程仍需设备测试。

首个可玩切片：1 个城镇入口与 1 张野外地图、3 种普通怪、精英变体、1 个 Boss、战士基础技能、经验和装备掉落、背包与存档。
