# 路线图与验收标准

## 产品方向

- 首发平台：Android 手机，竖屏优先；Mac 仅作为开发与桌面回归环境。
- 设计基准：720 × 1280 逻辑分辨率，适配常见 19.5:9 至 20:9 手机屏幕。
- 核心体验参照：小队探索、自动战斗、战利品、英雄成长、区域推进与 Boss 战。
- 美术、角色、数值、地图、技能与文案均为原创，不复刻其他游戏的可识别资产或表达。
- 核心玩法离线运行，本地存档，不依赖联网服务。

## 阶段与验收

| 阶段 | 目标 | 验收 |
|---|---|---|
| P0 | 工程基线 | Godot 可打开并运行，无缺失引用 |
| P1 | 竖屏地图与移动 | 竖屏布局、等距地图、触控摇杆、键鼠调试、边界和障碍碰撞 |
| P2 | 小队与自动战斗 | 3 名英雄跟随、自动索敌、普攻、技能、敌人 AI 与战斗结算 |
| P3 | 成长闭环 | 经验、装备、背包数据可保存恢复 |
| P4 | 首章内容 | 可从入口推进至 Boss 并通关 |
| P5 | 离线 Android | 飞行模式可玩，强制关闭后可恢复，APK 可安装 |
| P6 | 内容扩展 | 配置校验与核心回归通过 |
| P7 | 发布候选 | 无 P0/P1 缺陷，兼容性报告齐全 |

## 自动化质量门禁

每次推送到 main 或提交 Pull Request 时，GitHub Actions 使用 Godot 4.7.2 执行：
1. Headless Editor 导入与脚本解析。
2. 主场景 headless 启动回归。

自动化检查通过不等同于真实 Android 设备验收；触控手感、不同屏幕比例、性能和安装流程仍需设备测试。

首个可玩切片：1 张地图、3 名英雄（架构支持 6 人）、3 种普通怪、2 种精英、1 个 Boss、15–20 件装备、3–5 个技能样例，体验目标 10–25 分钟。

发布前验证：核心流程、离线运行、存档恢复、30 分钟稳定性、Android 安装与前后台切换。签名密钥不得提交仓库。
